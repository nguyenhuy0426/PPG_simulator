# Cyberdock V3 - bộ 6 STL

Gửi in thư mục GUI_IN_6_STL hoặc GUI_IN_6_STL.zip. Có đúng sáu STL cho 37 chi tiết; các file out/print là file trung gian phục vụ dựng/kiểm tra, không cần gửi riêng.

Màn hình 178 × 105 × 10 mm. Buồng tối bắt M4 lên bốn tai hộp Pi hiện tại; cả cụm trên cùng khay. Thân chính 220 × 170 × 150 mm (ngang × cao × sâu). Giữ cửa sau tháo được.

Dựng bằng môi trường CadQuery hiện có: build.py, rồi pack.py, verify.py, render.py. V3 có mã dựng riêng, không cần import thư mục V1. Kết quả kiểm tra ở out/verification.json.

Một số chi tiết được đặt đứng để xếp đủ sáu bàn; cần support/brim và kiểm tra slicing trước khi in PETG. Hướng dẫn chi tiết kèm trong bộ gửi in. Chưa in thử, thử tải/creep hoặc kiểm tra dây/cổng và hiệu chuẩn quang thực tế.
